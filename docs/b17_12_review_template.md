Use one copy of [the claim record](../results/b17_12/review_template.json) per claim. An empty record has status `NOT_RECEIVED`; a dispatch receipt, worker completion message, or manifest hash does not change it to accepted.

| Review step | Required evidence |
|---|---|
| Identify the statement | Field, group, degree, full partition, coefficient/dual/Borel convention, finite or quantified family scope; preserve independent z and all nine permanent entries. |
| Bind the source | Original proof, exact certificate, input and output SHA256, producer attribution, accepted inherited premises, and reviewer receipt. Record any path adaptation. |
| Check bound direction | Distinct fields for ideal lower q, ideal upper Q, coordinate upper B, coordinate lower L, source ceiling U and actual padding lower r. Exactness requires both directions. |
| Check globality | Polynomial coefficient identity on the full determinant orbit closure; denominators cleared with a density argument where needed. A rational chart identity or sampled zero is insufficient. |
| Check actual image | Explicit regular highest-weight functions on actual padding and exact independence. A source dimension or stabilizer-compatible vector is insufficient. Name basis ordering, normalization, minor and invertible substitution. |
| Check quantifiers | Prove every asserted degree/row range and stabilization. A failed onset, shared equation, local geometry or small negative control cannot supply an all-degree result. |
| Check review scope | Separate document review, arithmetic replay, independent implementation and shared mathematical premises. Include sign, support, duplicate-row and wrong-family controls where relevant. |
| Check resources | Issued lease receipt, priced support, pilot, actual command, one computation counter, interpreter/wrapper hashes, elapsed time, aggregate committed-memory peak and exit. A cap hit is uncomputed. Eligibility is not a lease. |
| Decide | Positive gap only from r>B, or q+r>a; full-cell exclusion from U<=L or Q+U<=a. Failure of q+U>a for an ideal floor only retires that certificate. Label separators and structural exclusions separately. |

For a claim advertised as beyond occurrence, require actual determinant occurrence (a positive coordinate lower bound or equivalent theorem). B>=1 alone is only an upper bound. For a size-growth claim, require a proved growing (m,n) inequality and a direct comparison to the benchmark. Jflag, full J24 and saturation receive different records.

Allowed review states are `NOT_RECEIVED`, `RECEIVED_UNREVIEWED`, `REVIEWED_SCOPED_PASS`, `REVIEWED_SCOPED_FAIL`, and `BLOCKED_FOR_SPECIFIC_INPUT`. Preserve a failed method as a result with its exact scope. Mathematical acceptance is an integrator/reviewer action recorded by receipt, not performed by this template.
