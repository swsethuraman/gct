## Why (the reasoning, logged in full so it can be judged later)

1. **The only known vanishing mechanism does not apply.** The parity/pigeonhole
   census — two letters occupying the same three brackets make a bracket
   monomial its own negative — kills every degree with `delta > C(delta/3,3)`,
   i.e. exactly `delta <= 15`. At `delta = 24`, `k = 8` and `C(8,3) = 56 >= 24`;
   the census permits it, and the ambient census confirms a nonzero space. No
   other mechanism forcing `Phi(det_3) = 0` is known in this programme.

2. **The one prior data point points the same way.** The only previously tested
   ambient invariant of a degree in `E`'s ambient support is `Phi_18`, and it
   does *not* vanish at `det_3` (it is `-877,879,296,000`). Nothing so far
   distinguishes 24 from 18 in a way that would flip the sign of that outcome.

3. **The symmetry that exists does not force vanishing — checked explicitly.**
   Restrict `Phi_24` to the 6-dimensional space `U` of cubics
   `F = sum_sigma u_sigma x_{1 sigma 1} x_{2 sigma 2} x_{3 sigma 3}`, which
   contains both `det_3` (`u = sgn`) and `perm_3` (`u = 1`). The 9-dimensional
   diagonal torus of `GL_9` preserves `U`, and the weight condition
   `sum_sigma e_sigma M_sigma = 8 J` has exactly the nine solutions
   `e = (a,a,a,8-a,8-a,8-a)`, `a = 0..8`. Hence

       Phi_24|_U  =  sum_{a=0}^{8} K_a P^a Q^{8-a},
       P = u_id u_c u_{c^2},   Q = u_{t1} u_{t2} u_{t3},

   a binary octic in `(P,Q)`. Row/column permutations `g` with
   `sgn(rho) sgn(pi) = -1` swap `P` and `Q` and have `det(g)^8 = 1`, so
   `K_a = K_{8-a}`. Then `P(det_3) = 1`, `Q(det_3) = -1`, giving

       Phi_24(det_3)  =  sum_a (-1)^a K_a  =  2(K_0 - K_1 + K_2 - K_3) + K_4,
       Phi_24(perm_3) =  sum_a K_a.

   The `P <-> Q` symmetry pairs `K_a` with `K_{8-a}`, and `a` and `8-a` have the
   *same* parity, so it does **not** annihilate the alternating sum. There is no
   representation-theoretic reason for `Phi_24(det_3)` to vanish. (The same
   computation at `delta = 18` gives `K'_a = K'_{6-a}`, `a = 0..6`, and there the
   alternating sum is indeed nonzero.)

4. **Genericity.** `Omega-bar` has dimension 64 in the 165-dimensional
   `Sym^3 C^9`. An invariant vanishing identically on it is a coincidence that
   wants a mechanism; none is in evidence.

5. **Semigroup shape.** `E/6` is a numerical semigroup of multiplicity 3
   containing 3 but not 1 or 2. `<3,4>` is the smallest such, and it is what the
   ambient Hilbert function `(0,0,0,0,0,1,0,1,...)` suggests if — as at 18 —
   ambient existence implies nonvanishing at `det_3`.

## The falsifier, and what a refutation would mean

`Phi_24(det_3) = 0` refutes this outright. It would establish
`E subset {0,18,30,36,42,...}` and make 30 the target, and it would be the first
evidence that ambient existence does *not* imply nonvanishing on the closure —
i.e. that the boundary deficit is arithmetically active at a rectangular weight.
That is a stronger and more interesting statement than the prediction, and it
would be logged as such.

## Method to be used (fixed now, before any value)

The unique ambient invariant is proportional to any nonvanishing bracket
monomial `B(S)`, `S` a 24-subset of the 56 triples of `[8]` in which every
bracket lies in exactly 9 triples. So for any single such `S`:

- run the evaluator with the six weights `u_sigma` set to `1` on even `sigma`
  and `t` on odd `sigma`; the result is `R_S(t) = sum_a K_a^{(S)} t^{24-3a}`
  where `B(S)|_U = c_S Phi_24|_U`;
- `R_S(t_0) != 0` at any `t_0` certifies `c_S != 0` (and `Phi_24|_U != 0`);
- then `24 in E` iff `R_S(-1) != 0`.

If `R_S == 0` for every `S` tried, `Phi_24|_U == 0` and `24 not in E`; that
direction needs `c_S != 0` to have been certified for some `S`, which the
`t_0`-run does.

Gates fixed in advance, all of which must pass before any degree-24 number is
reported:
- the same evaluator at `delta = 18` (6 brackets, 18 letters) must reproduce
  `R(-1)/R(+1) = -4725/272`, the banked `Phi_18(det_3)/Phi_18(perm_3)`;
- two different bracket structures `S`, `S'` must give `R_S/R_{S'}` constant in
  `t` (forced by `dim = 1`), and must agree on whether `R(-1) = 0`;
- exact arithmetic only.
