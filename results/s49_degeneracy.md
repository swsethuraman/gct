# The degeneracy-direction pre-check — the worked example (session 49)

`docs/brief_wording.md` §5 fixes a three-point test set and a rule: any statistic
proposed to characterise determinant type is evaluated at all three points before
anything is proved about it, and if it is at least as degenerate at the padded
permanent as at the determinant, it separates in the wrong direction.

The test set is committed under `tools/verify/testset/` (integer coefficients,
`random.Random(20260905 + 4900)`, box `±100`; regenerated byte-for-byte by
`make_testset.py`):

- `det_pencil.json` — `det_4(Σ_{i=1}^{10} s_i A_i)`, ten variables (715 monomials);
- `reducible.json` — `ℓ·c`, `c` a random cubic, ten variables (714 monomials);
- `padded_permanent.json` — the **full** `x_0·per_3(x_1..x_9)`, ten variables
  (6 monomials), the identity substitution — not a length-reduced restriction.

The worked example is the statistic of Proposition D (`docs/excess_singularity.md`):
the Macaulay corank `dim (S/J_F)_d` (larger = more singular = more degenerate),
computed modulo `p = 2147483647` by `tools/verify/testset/degeneracy_check.py`.

## Result

| point | `d=4` | `d=5` | `d=6` | `d=7` |
|---|---|---|---|---|
| `det_pencil` (r=10) | 615 | 1452 | 2996 | 5720 |
| `reducible` (r=10) | 615 | 1488 | 3174 | 6276 |
| `padded_permanent` (r=10) | **620** | **1538** | **3395** | **6881** |

The padded permanent is **strictly more degenerate than the determinant at every
degree, `d = 4` included** — so the corank statistic points the wrong way, as
Proposition D says it must.  The reducible point and the full padded permanent
also **disagree** (the pad is more degenerate than a generic `ℓ·c`), so the
restriction-vs-full distinction the check was built to expose is live here: a
control run only at `ℓ·(generic cubic)` would have under-reported the pad's
degeneracy.

Six-variable companions (restrictions, labelled as such):

| point | `d=4` | `d=5` | `d=6` | `d=7` | `d=8` |
|---|---|---|---|---|---|
| `det_pencil` (r=6) | 90 | 126 | 141 | 132 | 141 |
| `reducible` (r=6) | 90 | 136 | 191 | 266 | 370 |
| `padded_permanent` (r=6) | 90 | 136 | 191 | 266 | 370 |

The six-variable determinant coranks `(90, 126, 141, 132, 141)` at `d = 4..8`
reproduce, on the nose, the determinantal corank column of `docs/sixrow_cap.md`
§3 — an independent reproduction of the s44 Macaulay measurements by code
(`tools/verify/…`) that shares nothing with the s44 pipeline.

## Verdict

Both regimes return **WRONG DIRECTION**.  The check does in a minute what it is
meant to do; the worked example is Proposition D's inequality, exhibited at the
committed points.  Any future statistic runs through the same script first.
