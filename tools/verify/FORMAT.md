# The declared certificate format `gct-cert/1`

Session 49.  A certificate is one JSON object in a file `*.json` or `*.json.gz`
(UTF-8, gzip).  Integers are JSON numbers of arbitrary size (Python reads them
exactly).  The verifier (`tools/verify/verify.py`) rejects any file that departs
from this page — an unknown key, a missing key, a wrong type, a non-canonical
term — and reports it as **UNPARSEABLE** with the reason.  It never guesses.

Every certificate carries the four keys

| key | value |
|---|---|
| `format` | the string `"gct-cert/1"` |
| `kind` | `"hwv"`, `"matrix"` or `"full_rank"` |
| `title` | free text, one line |
| `produced_by` | free text: the script or session that wrote the file |

and optionally `notes` (free text).  Nothing else at top level beyond the keys
of its kind.

## Conventions the format fixes

The cell is `(n, r, λ, δ)` with `n = 4` (quartics), `r = ℓ(λ)` the number of
variables `s_1..s_r`, `|λ| = 4δ`; `a` is the ambient multiplicity of `S_λ(C^r)`
in `Sym^δ(Sym^4 C^r)`.

`C[Sym^4 C^r]` is generated by the **plain coefficient functionals**
`c_α(F) = [s^α] F`, `|α| = 4`.  A *term* is a multiset `{α^1, …, α^δ}` with an
integer coefficient, standing for `coeff · ∏_j c_{α^j}`; its weight is `Σ_j α^j`.
The Lie algebra acts by

    E_ij c_α = (α_i + 1) · c_{α + e_i − e_j}        (0 if α_j = 0),

extended to products as a derivation.  *Derivation, one line:* with
`(g·F)(s) = F(g^{-1}s)`, `E_ij` acts on forms by `−s_j ∂/∂s_i`, and on a linear
functional `h` by `(E·h)(F) = h(s_j ∂_i F)`; for `h = c_α` this is
`[s^α](s_j ∂_i F) = (α_i + 1)[s^{α+e_i−e_j}]F`.  *Check:* the discriminant
`b² − 4ac` of `a s_1² + b s_1 s_2 + c s_2²` is killed by `E_12` under this rule
(`E c_(0,2) = c_(1,1)`, `E c_(1,1) = 2 c_(2,0)`: `2b·2a − 4a·b = 0`) and is not
killed under the other candidate rule `α_j · c_{α+e_i−e_j}`, which is the rule
for the divided-power coordinates `α!·[s^α]F`.  A highest-weight vector is
annihilated by every `E_{i,i+1}`.

Because the rule and the coordinate are fixed here, every certificate states
them verbatim under `conventions`:

```json
"conventions": {"coefficient": "c_alpha(F) = coefficient of s^alpha in F",
                "raising":     "E_ij c_alpha = (alpha_i + 1) c_{alpha + e_i - e_j}"}
```

A file whose `conventions` differ by one character is unparseable.

## Evaluation points

A point is an object with a `type` and the **substitution data** that pins the
form; the verifier rebuilds the quartic from the data (`forms.py`) — that is the
check that the point lies on the claimed variety — and never accepts a bare
list of coefficients as a "det point" or a "pad point".

| type | data | the form |
|---|---|---|
| `det_pencil` | `pencil`: `r` integer `4×4` matrices `A_1..A_r` | `det_4(Σ s_i A_i)` |
| `padded_permanent` | `linear_forms`: ten integer vectors of length `r`, `x_0, x_1, …, x_9` | `x_0(s) · per_3(X(s))`, `X_{ab} = x_{1+3a+b}` |
| `reducible` | `l`: integer vector of length `r`; `cubic`: list of `[α, coeff]`, `|α| = 3` | `l(s) · c(s)` |
| `form` | `coefficients`: list of `[α, coeff]`, `|α| = 4` | the quartic itself (a generic point) |

Fresh points are drawn from `random.Random(seed + 1000·k)` with entries in
`[−1000, 1000]`, `k` the index of the family in
`(det_pencil, padded_permanent, reducible, generic)`; the seed is in the
certificate, so every fresh point is reproducible and can be written down.

## Kind `hwv` — highest-weight vectors and what they vanish on

```json
{"format": "gct-cert/1", "kind": "hwv", "title": "...", "produced_by": "...",
 "cell": {"n": 4, "r": 6, "lambda": [13,10,6,1,1,1], "delta": 8, "a": 9},
 "conventions": {...},
 "modulus": null,
 "vectors": [{"terms": [[[[0,0,3,0,0,1],[0,3,0,0,1,0],...,[4,0,0,0,0,0]], 1], ...]}],
 "claims": {"independent": true,
            "star_support": {"k": 1},
            "vanishes_at": [ <points> ],
            "nonvanishing_at": [ <points> ],
            "fresh_points": {"seed": 20260905, "count": 6,
                             "vanishes_on": ["padded_permanent", "reducible"],
                             "nonvanishing_on": ["det_pencil", "generic"]}}}
```

- `modulus`: `null` for integer vectors; a prime `p` for vectors known only
  modulo `p` (coefficients in `[1, p−1]`).  A mod-`p` vector is checked modulo
  `p` throughout and the report says so; it is never promoted to an integer
  certificate.
- `vectors`: each `terms` list is sorted, its entries distinct, every factor
  list sorted (the canonical multiset), every `α` of length `r` and degree 4,
  every term of weight exactly `λ`, no zero coefficients.
- `claims` (all optional): `independent` — the vectors are linearly independent
  (rank over `Q`, or mod `p`); `star_support` — every term has, for every
  variable index `i`, a factor with `α_i ≤ k−1`, which by Theorem (★) of
  `docs/reducible_ideal.md` puts the vector in the ideal of `{l^k · c}`;
  `vanishes_at` — the vectors vanish at each recorded point;
  `nonvanishing_at` — the evaluation matrix (vectors × points) has full row rank
  (for one vector: nonzero at some listed point); `fresh_points` — the same two
  demands at `count` fresh points of each named family.

What the verifier does with it: cell consistency (`n = 4`, `ℓ(λ) = r`,
`|λ| = 4δ`, `λ` weakly decreasing, `a` recomputed by the Weyl alternation of
`pleth.py`), the shape checks above, the weight of every term, every simple
raising operator over `Z` (or mod `p`), independence, (★), and every point.

## Kind `matrix` — layer 1 on a serialised integer matrix

```json
{"format": "gct-cert/1", "kind": "matrix", "title": "...", "produced_by": "...",
 "matrix": [[...], ...]            or   {"shape": [m, n], "entries": [[i, j, v], ...]},
 "matrix_source": {"type": "macaulay_det_pencil", "n": 4, "r": 6, "d": 7, "pencil": [A_1, ..., A_6]},
 "claimed_rank_Q": 660,
 "claimed_ranks_mod_p": {"2147483647": 660, "2147483629": 660},
 "nonvanishing_minor": {"rows": [...], "cols": [...]},
 "nullity_zero": {"prime": 2147483647}}
```

At least one of `matrix`, `matrix_source`, and at least one claim.  With a
`matrix_source` the verifier rebuilds the Macaulay matrix of the `r` partials of
`det_4` of the recorded pencil (rows `(i, m)`, `m` of degree `d−3`, columns the
monomials of degree `d`, both in the lexicographic order of `layer1.monomials`)
and, if a `matrix` is also recorded, requires the two to coincide entry by
entry.  Then: the rank over `Q` **exactly** — a rank modulo one prime is the
lower bound, and the vanishing of every `(r_0+1)`-minor modulo enough 62-bit
primes to exceed twice the Hadamard bound is the upper bound; the rank modulo
every recorded prime and modulo both house primes; the named minor's
determinant over `Z` (flint for small minors, Chinese remaindering above the
Hadamard bound otherwise); and the nullity-zero claim at its prime.

## Kind `full_rank` — `mult_X(λ, δ) = a` at a cell

```json
{"format": "gct-cert/1", "kind": "full_rank", "title": "...", "produced_by": "...",
 "cell": {...}, "conventions": {...},
 "prime": 2147483647,
 "variety": "det_pencil",
 "points": [ <points of that type> ],
 "basis": null   or   [ {"terms": ...}, ... ]}
```

The verifier recomputes `a`; takes the highest-weight space modulo `p` either
by recomputing the kernel of the raising operators (weight spaces up to
`layer2.KERNEL_CAP` monomials) or from the recorded `basis`, each vector of
which must be a highest-weight vector modulo `p`, the basis independent with
exactly `a` members; evaluates the basis at the recorded points; and requires
rank `a` modulo `p`.  Since `rank_p ≤ rank_Q ≤ a`, a pass proves
`mult_X(λ, δ) = a` over `Q` — *provided the points lie on `X`*, which is why the
points must be given by substitution data and not by coefficients.  A cell
beyond the cap with no recorded basis is reported as **not verified**, not as
verified.

## Exit status and report

`verify.py` prints one line per file (`PASS`, `FAIL`, `UNPARSEABLE`, `ERROR`)
followed by every check with its outcome, writes the same as Markdown with
`--report <file>`, and exits 0 only when every file passed.
